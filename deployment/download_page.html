❓ Frequently Asked Questions

Q: Do I need Python installed?

No! Python is included in the installer. You just need to run the setup and everything is included.

Q: What formats does it support?

The application works with PDF files containing picking slips (R D format) or delivery dockets (Route No. format).

Q: Where are the output files saved?

By default, all merged PDFs are automatically saved to your Downloads folder (C:\Users\YourName\Downloads).

Q: Can I use it on multiple computers?

Yes! You can install it on any Windows computer. Each installation can be used independently.

Q: Is my data private?

Absolutely. All processing happens on your computer locally. No files are uploaded to any server.

Q: How do I uninstall?

Go to Control Panel > Programs > Programs and Features, find "HDS Route Sequencer", and click Uninstall.
