HDS ROUTE SEQUENCER v1.0.0
Professional PDF Route Sequencing & Merging Application

================================================================================
INSTALLATION
================================================================================

1. Download: HDS_Route_Sequencer_Setup.exe

2. Run the installer:
   - Double-click HDS_Route_Sequencer_Setup.exe
   - Click "Next" through the installation wizard
   - Select installation location (default: C:\Program Files\HDS Route Sequencer)
   - Click "Install"
   - Wait for installation to complete

3. Start the application:
   - Click Start Menu → HDS Route Sequencer
   - Or double-click "HDS Route Sequencer" on your Desktop

HOW TO USE
================================================================================

1. Launch the application
2. Choose processing mode:
   - Picking Slips (R D format)
   - Delivery Dockets (Route No. format)
3. Add PDF files:
   - Drag and drop files into the drop zone, OR
   - Click "+ Add Files" button
4. Preview routes (optional):
   - Click "👁️ Preview Routes" to see detected routes before processing
5. Process files:
   - Click "🔗 Merge & Sequence"
   - Files automatically save to Downloads folder
   - Progress bar shows completion status
6. View results:
   - Success dialog shows statistics
   - Click "📂 Open Output Folder" to view merged files

================================================================================
TROUBLESHOOTING
================================================================================

Q: "Application won't start"
A: Restart your computer. If problem persists, uninstall and reinstall.

Q: "Antivirus blocks the application"
A: This is normal for new applications. Add to antivirus whitelist.

Q: "Downloaded PDF is corrupted"
A: This indicates an issue with the input files. Test with sample PDFs.

Q: "Progress bar seems frozen"
A: Processing may be slow with large files. This is normal - progress updates every few seconds.

Q: "Files don't appear in Downloads folder"
A: Check Downloads folder directly (C:\Users\YourName\Downloads)

Q: "Permission denied when trying to uninstall"
A: Run uninstaller as Administrator (right-click → Run as Administrator)
